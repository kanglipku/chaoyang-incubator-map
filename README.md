# 朝阳区产业孵化器地图（Demo）

把朝阳区各片区产业孵化器的标准化资料放到地图上，点击地图标记即可查看园区详情。

## 项目结构

```
chaoyang-incubator-map/
├── index.html          # 主页面：地图 + 筛选 + 详情页（双击即可打开）
├── data.js             # 园区数据（网页读取的数据源，由脚本自动生成）
├── data.csv            # 园区数据（Excel 可编辑的版本）
├── photos/             # 园区照片（按园区 id 分目录）
├── lib/                # Leaflet 地图库（已本地化）
└── scripts/
    ├── obsidian_parser.py  # ★ 从 Obsidian 笔记同步园区信息（主数据源，日常更新用这个）
    ├── build_data.py       # 从内置台账生成全量数据（初始/重建用）
    └── csv2js.py           # 把 data.csv 转成 data.js（Excel 手动编辑后用）
```

## 📌 Obsidian 数据源工作流（推荐）

**日常更新园区信息，只改 Obsidian 笔记，不碰代码：**

1. 在 Obsidian 的 `工作/3-2 企业落地/园区信息/` 目录新建或修改笔记，格式：
   ```
   ［园区］园区名称
   ［面积］1万㎡独栋 10028.57㎡
   ［报价］5-7元/天/平
   ［其他费用］物业费18元/月/平；水费9.5元/吨
   ［商务条款］押三付三
   ［地铁］14号线将台站
   ［配套］食堂、咖啡厅、接驳班车
   ```
   （也支持 `【项目】【租赁面积】【物业费】【入驻企业】` 等标签；图片用 `![](图片路径)` 插入）
2. 运行 `python3 scripts/obsidian_parser.py`：
   - 笔记名与现有园区匹配 → **数据对齐更新**，自动记录「更新时间 + 更新内容」（详情页"📝 更新动态"可折叠查看）
   - 没匹配到的笔记 → **自动新增园区**，照片自动拷贝进 `photos/`
3. 重新部署到 GitHub Pages，线上自动更新。

## 项目功能

- 🗺 全屏地图：朝阳区边界高亮、邻区淡灰底，园区标记带图标、名称与**级别角标**（国/市/区/校）
- 🎖 载体分级：国家级 > 省市级 > 区级 > 校级 > 其他（角标与图例颜色对应）
- 📷 详情页照片轮播：链家式大图 + 左右切换 + 缩略图（有照片的园区自动展示）
- 📝 更新动态折叠：每次 Obsidian 对齐更新的时间和内容记录，可展开查看
- 🏢 租区/物业信息：租金报价、物业费、层高、入驻企业等（来自笔记的明细字段）
- ⚖️ 园区对比：勾选最多 5 个园区，懂车帝式对比表（最优值蓝色高亮）
- 🔍 增强筛选：搜索 / 街道 / 类型 / **载体级别 / 用地类型 / 租金区间 / 仅看有照片** / 排序（租金、企业数、面积）
- 🏭 当前收录 **30 个真实园区**：科技孵化器 20、文创园区 2、综合孵化器 2、数字经济 6（国家级 8、省市级 15、区级 2、校级 1、其他 4）

## 怎么用（零成本）

1. **本地使用**：直接双击 `index.html`，浏览器打开即可浏览地图和园区信息。
2. **加数据**：用 Excel / WPS 打开 `data.csv`，每个园区一行，按表头填好
   （多值字段如"聚焦领域"用 `|` 分隔，如 `人工智能|云计算`）。
3. **更新页面数据**：终端里在项目目录运行 `python3 scripts/csv2js.py`，
   然后刷新浏览器即可（旧 data.js 会自动备份为 data.js.bak）。
4. **发布到公网（免费，无需买域名）**：把整个文件夹传到以下任一平台即可：
   - **GitHub Pages**：项目仓库 → Settings → Pages，选分支发布；
   - **Cloudflare Pages**：登录 dashboard 直接拖拽上传文件夹；
   - **腾讯云 EdgeOne Pages / CloudBase 静态托管**：国内访问快，有免费额度；
   - 国内访问建议优先选后两个，避免海外 CDN 慢的问题。

> 云盘（百度网盘等）只能存文件、不能运行网页，所以不能直接托管网站；
> 但本项目是纯静态网页 + 数据文件，上述免费托管方案完全够用，不需要买域名和服务器。

## 注意事项

- **数据来源**：30 个园区的基础信息（名称/地址/资质）来自公开官方渠道——北京市科委及中关村孵化器名录、北京市中小企业服务地图（市经信局）、朝阳区政府及文旅局示范园区名单、各园区官网（望京留创园 wjpark.com、751 官网 751info.com、普天电子城 506fhq.com、北影文创园 dianyingpark.cn 等），每条数据在 `source` 字段注明出处。
- **行业指标为估算值**：环评/危废/生物安全/GMP/租金等字段按园区类型模板生成，标注"待核实"的字段请逐项现场调研后替换（改 `data.csv` → 运行 `csv2js.py`）。
- **用地类型国标代码**：M1 一类工业用地（无污染工业/中试）、M2 二类工业用地（轻度污染）、M3 三类工业用地（重污染）、A35 科研设计用地、B2 商务用地、C65 文化创意用地（原工业遗产改造）。
- **覆盖范围**：聚焦科技类载体 28 家——国家级 8 家（望京留创园、创E+、普天电子城、牡丹、瀚海博智、时代凌宇、北京创业大厦、创业黑马），省市级 14 家（含中关村硬科技孵化器、2025 中关村特色产业园：AI Space、未来显示产业园、望京生命科学园等），区级 2 家（金盏、E9区），校级 1 家（北工大山河湾谷），其他 3 家；文创园区已按需求移除。区级备案众创空间等载体尚有数十家未收录，可在 `data.csv` 按模板持续补充。
- 地图瓦片使用高德 / 腾讯 / OpenStreetMap 免费在线瓦片，浏览页面时需要联网。
- 一键导航调用高德地图网页版（uri.amap.com），坐标按 GCJ-02 坐标系直接可用。
